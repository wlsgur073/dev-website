## _shared 폴더 의미
- `./packages/backend/_shared/`는 도메인 공통 문서를 모아두는 영역이다.
- `./packages/backend/_shared/conventions/`는 문서 규칙/네이밍/링킹/생성 리포트를 관리한다.
- `./packages/backend/_shared/templates/`는 문서 템플릿을 관리한다.
- `./packages/backend/_shared/adr/`는 아키텍처 결정 기록을 관리한다(현재 문서 없음).
- `./packages/backend/_shared/runbooks/`는 운영 절차 문서를 관리한다(현재 문서 없음).
- `./packages/backend/_shared/exception/`는 전역 예외 문서를 관리한다(현재 문서 없음).
