## 주요 설정 파일

### vite.config.ts

```typescript
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  },
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      }
    }
  }
})
```

- `@` 경로 별칭으로 `src/` 디렉토리 접근
- 개발 서버에서 `/api` 요청을 백엔드로 프록시

### tsconfig.json

- TypeScript strict 모드 활성화
- ES2020 타겟
- 경로 매핑: `@/*` → `src/*`

## 디렉토리별 역할

### `src/api/`

백엔드 API와의 통신을 담당하는 모듈들이 위치합니다.

| 파일 | 역할 |
|------|------|
| `http.ts` | Axios 인스턴스 생성, 요청/응답 인터셉터, 토큰 갱신 로직 |
| `auth.ts` | 로그인, 회원가입, 로그아웃, 토큰 갱신 API |
| `announcements.ts` | 공지사항 CRUD API |
| `releases.ts` | 릴리스 CRUD API |
| `apikeys.ts` | API 키 관리 API |
| `subscription.ts` | 구독 및 사용량 통계 API |
| `plans.ts` | 플랜 정보 조회 API |
| `generated.ts` | OpenAPI 스펙에서 자동 생성된 타입 정의 |

자세한 내용: [[03-API-모듈]]

### `src/stores/`

Pinia를 사용한 전역 상태 관리 스토어입니다.

| 파일 | 역할 |
|------|------|
| `auth.ts` | 인증 상태 (토큰, 사용자 정보, 로그인/로그아웃) |
| `theme.ts` | 테마 상태 (light/dark/system) |
| `index.ts` | 스토어 export |

자세한 내용: [[05-상태관리-Pinia]]

### `src/router/`

Vue Router 설정 및 네비게이션 가드가 정의됩니다.

- 라우트 정의 (공개/인증/관리자)
- 동적 import를 통한 코드 분할
- 인증 상태 기반 접근 제어

자세한 내용: [[02-라우팅-시스템]]

### `src/layouts/`

페이지를 감싸는 레이아웃 컴포넌트입니다.

| 레이아웃 | 구성 | 사용처 |
|---------|------|--------|
| `DefaultLayout` | 헤더 + 콘텐츠 + 푸터 | 일반 공개 페이지 |
| `AuthLayout` | 중앙 정렬 폼 | 로그인/회원가입 |
| `DocsLayout` | 헤더 + 사이드바 + 콘텐츠 + TOC + 푸터 | 문서 페이지 |
| `ConsoleLayout` | 상단바 + 좌측 네비 + 콘텐츠 | 콘솔 대시보드 |
| `AdminLayout` | (코드로 확인 불가) | 관리자 페이지 |

자세한 내용: [[06-레이아웃-컴포넌트]]

### `src/pages/`

라우트와 매핑되는 페이지 컴포넌트입니다.

#### 공개 페이지
- `HomePage.vue` - 메인 랜딩 페이지
- `ApiDocsPage.vue` - API 문서
- `PricingPage.vue` - 가격 정책
- `CommunityPage.vue` - 커뮤니티
- `SearchPage.vue` - 검색

#### 인증 페이지
- `auth/LoginPage.vue` - 로그인
- `auth/RegisterPage.vue` - 회원가입

#### 콘솔 페이지 (인증 필요)
- `console/ConsolePage.vue` - 대시보드
- `console/ConsoleApiKeysPage.vue` - API 키 관리
- `console/ConsoleBillingPage.vue` - 결제 관리

#### 관리자 페이지 (관리자 권한 필요)
- `admin/AdminAnnouncementsPage.vue` - 공지사항 관리
- `admin/AdminReleasesPage.vue` - 릴리스 관리
