# 인증 프로세스

## 개요

JWT(JSON Web Token) 기반의 인증 시스템입니다. Access Token은 메모리에, Refresh Token은 HttpOnly 쿠키에 저장됩니다.

## 토큰 구조

| 토큰 | 저장 위치 | 만료 시간 | 용도 |
|------|----------|----------|------|
| Access Token | Pinia Store (메모리) | 코드로 확인 불가 | API 요청 인증 |
| Refresh Token | HttpOnly 쿠키 | 코드로 확인 불가 | Access Token 갱신 |

## 로그인 프로세스

### 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor User as 사용자
    participant LP as LoginPage
    participant AS as authStore
    participant API as authApi
    participant HTTP as http.ts
    participant Backend as 백엔드
    participant Router as Vue Router

    User->>LP: 이메일/비밀번호 입력
    User->>LP: 로그인 버튼 클릭

    LP->>LP: 로딩 상태 설정
    LP->>AS: login(email, password)

    AS->>AS: isLoading = true
    AS->>API: login(email, password)
    API->>HTTP: POST /auth/login

    HTTP->>Backend: 요청 전송
    Backend-->>HTTP: { accessToken, user }
    Note over Backend,HTTP: Set-Cookie: refreshToken (HttpOnly)

    HTTP-->>API: 응답 데이터
    API-->>AS: { accessToken, user }

    AS->>AS: accessToken 저장
    AS->>AS: user 저장
    AS->>AS: isLoading = false

    AS-->>LP: 성공

    LP->>Router: push('/console')
    Note over LP,Router: 또는 query.redirect 경로로 이동

    Router-->>User: 대시보드 페이지 표시
```

### 흐름도

```mermaid
flowchart TD
    A[로그인 페이지 접근] --> B[이메일/비밀번호 입력]
    B --> C[로그인 버튼 클릭]
    C --> D{입력값 유효성 검사}
    D -->|실패| E[에러 메시지 표시]
    E --> B
    D -->|성공| F[API 호출]
    F --> G{로그인 성공?}
    G -->|실패| H[에러 메시지 표시]
    H --> B
    G -->|성공| I[토큰 저장]
    I --> J[사용자 정보 저장]
    J --> K{redirect 파라미터 있음?}
    K -->|예| L[redirect 경로로 이동]
    K -->|아니오| M[/console로 이동]
```

### 에러 처리

| 상태 코드 | 원인 | 사용자 메시지 |
|----------|------|-------------|
| 400 | 잘못된 요청 형식 | "이메일과 비밀번호를 입력해주세요" |
| 401 | 인증 실패 | "이메일 또는 비밀번호가 올바르지 않습니다" |
| 429 | 요청 제한 초과 | "잠시 후 다시 시도해주세요" |
| 500 | 서버 오류 | "서버 오류가 발생했습니다" |

## 회원가입 프로세스

### 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor User as 사용자
    participant RP as RegisterPage
    participant AS as authStore
    participant API as authApi
    participant Backend as 백엔드
    participant Router as Vue Router

    User->>RP: 이름/이메일/비밀번호 입력
    User->>RP: 가입 버튼 클릭

    RP->>RP: 로컬 유효성 검사
    Note over RP: 비밀번호 일치 확인<br/>비밀번호 8자 이상

    alt 유효성 검사 실패
        RP-->>User: 에러 메시지 표시
    else 유효성 검사 성공
        RP->>AS: register(name, email, password)
        AS->>API: register(name, email, password)
        API->>Backend: POST /auth/register

        alt 가입 성공
            Backend-->>API: { accessToken, user }
            API-->>AS: 응답 데이터
            AS->>AS: 토큰/사용자 저장
            AS-->>RP: 성공
            RP->>Router: push('/console')
        else 가입 실패
            Backend-->>API: 에러 응답
            API-->>AS: 에러
            AS-->>RP: 에러
            RP-->>User: 에러 메시지 표시
        end
    end
```

### 클라이언트 측 유효성 검사

```typescript
// RegisterPage.vue
const validateForm = () => {
  if (password !== confirmPassword) {
    error.value = '비밀번호가 일치하지 않습니다'
    return false
  }
  if (password.length < 8) {
    error.value = '비밀번호는 8자 이상이어야 합니다'
    return false
  }
  return true
}
```

```mermaid
sequenceDiagram

    participant Header as AppHeader
    participant AS as authStore
    participant API as authApi
    participant Backend as 백엔드
    participant Router as Vue Router

    User->>Header: 로그아웃 버튼 클릭
    Header->>AS: logout()

    AS->>API: logout()
    API->>Backend: POST /auth/logout
    Note over Backend: Refresh Token 무효화<br/>쿠키 삭제

    Backend-->>API: 성공
    API-->>AS: 완료

    AS->>AS: accessToken = null
    AS->>AS: user = null

    AS-->>Header: 완료
    Header->>Router: push('/')

    Router-->>User: 홈페이지 표시
```

### 로그아웃 흐름도

```mermaid
flowchart TD
    A[로그아웃 버튼 클릭] --> B[authStore.logout 호출]
    B --> C[POST /auth/logout]
    C --> D{API 호출 성공?}
    D -->|성공| E[로컬 상태 정리]
    D -->|실패| E

    F --> G[user = null]

```

## 앱 초기화 시 인증 복구

페이지 새로고침 시 메모리의 토큰이 손실되므로, 앱 시작 시 토큰 갱신을 시도합니다.

### 시퀀스 다이어그램

```mermaid
sequenceDiagram
    participant App as App.vue
    participant Router as Vue Router
    participant AS as authStore
    participant API as authApi
    participant Backend as 백엔드

    App->>Router: 라우트 변경
    Router->>Router: beforeEach 가드

    Router->>AS: initAuth()

    alt 이미 초기화됨
        AS-->>Router: 즉시 반환
    else 초기화 필요
        AS->>API: refresh()
        API->>Backend: POST /auth/refresh
        Note over API,Backend: HttpOnly 쿠키로 인증

        alt 갱신 성공
            Backend-->>API: { accessToken }
            API-->>AS: 새 토큰
            AS->>AS: accessToken 저장
            AS->>API: getCurrentUser()
            API->>Backend: GET /auth/me
            Backend-->>API: User 정보
            API-->>AS: User 정보
            AS->>AS: user 저장
        else 갱신 실패
            Backend-->>API: 401 에러
            API-->>AS: 에러
            AS->>AS: 미인증 상태 유지
        end

        AS->>AS: isInitialized = true
        AS-->>Router: 완료
    end

    Router->>Router: 라우트 가드 계속 진행
```

### 초기화 흐름도

```mermaid
flowchart TD
    A[앱 시작] --> B{isInitialized?}
    B -->|예| C[즉시 반환]
    B -->|아니오| D[refresh API 호출]
    D --> E{성공?}
    E -->|예| F[accessToken 저장]
    F --> G[getCurrentUser 호출]
    G --> H[user 저장]
    H --> I[isInitialized = true]
    E -->|아니오| J[미인증 상태 유지]
    J --> I
    I --> K[라우트 가드 계속]
    C --> K
```

## 보호된 라우트 접근

### 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor User as 사용자
    participant Router as Vue Router
    participant AS as authStore
    participant LP as LoginPage
    participant CP as ConsolePage

    User->>Router: /console 접근

    Router->>Router: beforeEach 가드
    Router->>AS: isAuthenticated 확인

    alt 인증됨
        AS-->>Router: true
        Router->>Router: requiresAdmin 확인

        alt 관리자 라우트
            Router->>AS: isAdmin 확인
            alt 관리자임
                AS-->>Router: true
                Router->>CP: 페이지 렌더링
            else 관리자 아님
                AS-->>Router: false
                Router->>Router: /403으로 리다이렉트
            end
        else 일반 보호 라우트
            Router->>CP: 페이지 렌더링
        end
    else 미인증
        AS-->>Router: false
        Router->>LP: /login?redirect=/console
    end
```

## 전체 인증 상태 흐름도

```mermaid
stateDiagram-v2
    [*] --> 미인증: 앱 시작

    미인증 --> 초기화중: initAuth 호출
    초기화중 --> 인증됨: 토큰 갱신 성공
    초기화중 --> 미인증: 토큰 갱신 실패

    미인증 --> 로그인중: login 호출
    로그인중 --> 인증됨: 로그인 성공
    로그인중 --> 미인증: 로그인 실패

    미인증 --> 회원가입중: register 호출
    회원가입중 --> 인증됨: 가입 성공
    회원가입중 --> 미인증: 가입 실패

    인증됨 --> 토큰갱신중: 401 에러 발생
    토큰갱신중 --> 인증됨: 갱신 성공
    토큰갱신중 --> 미인증: 갱신 실패

    인증됨 --> 미인증: logout 호출
```
