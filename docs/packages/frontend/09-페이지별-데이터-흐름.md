# 페이지별 데이터 흐름

## 개요

주요 페이지들의 데이터 로딩 패턴과 상태 관리 흐름을 설명합니다.

## HomePage (홈 페이지)

### 데이터 흐름

```mermaid
sequenceDiagram
    participant HP as HomePage
    participant AA as announcementsApi
    participant RA as releasesApi
    participant Backend as 백엔드

    HP->>HP: onMounted()

    par 병렬 데이터 로딩
        HP->>AA: getLatestAnnouncements(3)
        AA->>Backend: GET /announcements/latest?limit=3
        Backend-->>AA: 최신 공지사항 3개
        AA-->>HP: announcements

        HP->>RA: getLatestReleases(3)
        RA->>Backend: GET /releases/latest?limit=3
        Backend-->>RA: 최신 릴리스 3개
        RA-->>HP: releases
    end

    HP->>HP: 화면 렌더링
```

### 상태 관리

```typescript
// 로컬 상태
const announcements = ref<Announcement[]>([])
const releases = ref<Release[]>([])
const loading = ref({ announcements: true, releases: true })
const error = ref({ announcements: null, releases: null })
```

### 에러 처리

각 데이터 소스의 로딩/에러 상태를 독립적으로 관리합니다.

```mermaid
flowchart TD
    A[데이터 로딩 시작] --> B{성공?}
    B -->|예| C[데이터 표시]
    B -->|아니오| D[에러 메시지 표시]
    D --> E[재시도 버튼 표시]
```

## ConsolePage (대시보드)

### 데이터 흐름

```mermaid
sequenceDiagram
    participant CP as ConsolePage
    participant AK as apikeysApi
    participant SA as subscriptionApi
    participant AS as authStore
    participant Backend as 백엔드

    CP->>CP: onMounted()

    par 병렬 데이터 로딩
        CP->>AK: getApiKeys()
        AK->>Backend: GET /apikeys
        Backend-->>AK: API 키 목록
        AK-->>CP: apiKeys

        CP->>SA: getUsageStats()
        SA->>Backend: GET /subscription/usage
        Backend-->>SA: 사용량 통계
        SA-->>CP: usageStats
    end

    CP->>AS: user
    AS-->>CP: 사용자 정보

    CP->>CP: 화면 렌더링
```

### 표시 데이터

| 섹션 | 데이터 소스 | 표시 내용 |
|------|-----------|----------|
| 환영 인사 | authStore.user | 사용자 닉네임 |
| API Calls Today | usageStats | 오늘 호출 수 / 일일 한도 |
| Active API Keys | apiKeys | API 키 개수 |
| Current Plan | 코드로 확인 불가 | Free (하드코딩 추정) |
| 월간 사용량 | usageStats | 이번 달 호출 수 / 월간 한도 |

### 진행률 바 색상 로직

```mermaid
flowchart TD
    A[사용량 계산] --> B{사용률}
    B -->|90% 이상| C[빨간색]
    B -->|70% ~ 90%| D[노란색]
    B -->|70% 미만| E[파란색]
```

## ConsoleApiKeysPage (API 키 관리)

### 데이터 흐름

```mermaid
sequenceDiagram
    participant Page as ApiKeysPage
    participant API as apikeysApi
    participant Toast as useToast
    participant Backend as 백엔드

    Page->>Page: onMounted()
    Page->>API: getApiKeys()
    API->>Backend: GET /apikeys
    Backend-->>API: API 키 목록
    API-->>Page: apiKeys

    Note over Page: 사용자 액션

    alt API 키 생성
        Page->>API: createApiKey(name, expiresAt?)
        API->>Backend: POST /apikeys
        Backend-->>API: 새 API 키 (key 포함)
        API-->>Page: newApiKey
        Page->>Toast: success('API 키가 생성되었습니다')
        Page->>Page: 목록에 추가
        Note over Page: 키 값은 이때만 표시됨
    else API 키 삭제
        Page->>API: deleteApiKey(id)
        API->>Backend: DELETE /apikeys/:id
        Backend-->>API: 성공
        API-->>Page: 완료
        Page->>Toast: success('API 키가 삭제되었습니다')
        Page->>Page: 목록에서 제거
    else API 키 재생성
        Page->>API: regenerateApiKey(id)
        API->>Backend: POST /apikeys/:id/regenerate
        Backend-->>API: 새 키 값
        API-->>Page: updatedApiKey
        Page->>Toast: success('API 키가 재생성되었습니다')
        Page->>Page: 목록 업데이트
    end
```

### 상태 관리

```typescript
const apiKeys = ref<ApiKey[]>([])
const loading = ref(true)
const showCreateModal = ref(false)
const newKeyName = ref('')
const newKeyExpiry = ref('')
const createdKey = ref<string | null>(null)  // 생성된 키 (한 번만 표시)
```

## DocsSlugPage (문서 상세)

### 데이터 흐름

```mermaid
sequenceDiagram
    participant Page as DocsSlugPage
    participant Content as content/docs
    participant MR as MarkdownRenderer
    participant Router as Vue Router

    Page->>Page: onMounted()
    Page->>Router: route.params.slug
    Router-->>Page: 'quickstart'

    Page->>Content: loadDocContent('quickstart')
    Content->>Content: import.meta.glob으로 .md 파일 로드
    Content-->>Page: markdown 콘텐츠

    alt 문서 존재
        Page->>MR: content 전달
        MR->>MR: 마크다운 파싱
        MR->>MR: 코드 하이라이팅
        MR->>MR: TOC 추출
        MR-->>Page: toc (emit)
        Page->>Page: TOC 표시
    else 문서 없음
        Page->>Router: push('/404')
    end
```

### watch를 통한 동적 로딩

```typescript
// route.params.slug 변경 감지
watch(
  () => route.params.slug,
  async (newSlug) => {
    await loadContent(newSlug as string)
  },
  { immediate: true }
)
```

### 이전/다음 문서 네비게이션

```mermaid
flowchart LR

    B -->|예| C[이전 버튼 표시]
    B -->|아니오| D[이전 버튼 숨김]

    A --> E{다음 문서 있음?}
    E -->|예| F[다음 버튼 표시]
```

## ReleasesPage / AnnouncementsPage (목록 페이지)

### 페이지네이션 데이터 흐름

```mermaid
sequenceDiagram
    participant Page as ListPage
    participant API as api
    participant Backend as 백엔드

    Page->>Page: onMounted()
    Page->>API: getList({ page: 0, size: 10 })
    API->>Backend: GET /items?page=0&size=10
    Backend-->>API: { content, totalPages, totalElements }
    API-->>Page: 페이지 데이터

    Note over Page: 페이지 변경

    Page->>Page: goToPage(2)
    Page->>API: getList({ page: 2, size: 10 })
    API->>Backend: GET /items?page=2&size=10
    Backend-->>API: 페이지 데이터
    API-->>Page: 업데이트된 데이터
```

### 상태 구조

```typescript
interface PageState<T> {
  items: T[]
  loading: boolean
  error: string | null
  pagination: {
    page: number
    size: number
    totalPages: number
    totalElements: number
  }
}
```

## 관리자 페이지 (Admin)

### CRUD 데이터 흐름

```mermaid
sequenceDiagram
    participant Page as AdminPage
    participant API as api
    participant Toast as useToast
    participant Backend as 백엔드

    Note over Page: 목록 조회
    Page->>API: getList()
    API->>Backend: GET /admin/items
    Backend-->>API: 목록 데이터
    API-->>Page: items

    Note over Page: 생성
    Page->>API: create(data)
    API->>Backend: POST /admin/items
    Backend-->>API: 새 항목
    API-->>Page: newItem
    Page->>Toast: success('생성되었습니다')
    Page->>Page: 목록 새로고침

    Note over Page: 수정
    Page->>API: update(id, data)
    API->>Backend: PUT /admin/items/:id
    Backend-->>API: 수정된 항목
    API-->>Page: updatedItem
    Page->>Toast: success('수정되었습니다')
    Page->>Page: 목록 새로고침

    Note over Page: 삭제
    Page->>API: delete(id)
    API->>Backend: DELETE /admin/items/:id
    Backend-->>API: 성공
    API-->>Page: 완료
    Page->>Toast: success('삭제되었습니다')
    Page->>Page: 목록에서 제거
```

### 모달 상태 관리

```typescript
const showModal = ref(false)
const editingItem = ref<Item | null>(null)
const isEditMode = computed(() => editingItem.value !== null)

// 생성 모드
const openCreateModal = () => {
  editingItem.value = null
  showModal.value = true
}

// 수정 모드
const openEditModal = (item: Item) => {
  editingItem.value = item
  showModal.value = true
}
```

## 공통 데이터 로딩 패턴

### 로딩 상태 표시

```mermaid
flowchart TD
    A[컴포넌트 마운트] --> B[loading = true]
    B --> C[API 호출]
    C --> D{성공?}
    D -->|예| E[데이터 저장]
    D -->|아니오| F[에러 저장]
    E --> G[loading = false]
    F --> G

    subgraph UI 렌더링
        H{loading?}
        H -->|예| I[로딩 스피너]
        H -->|아니오| J{error?}
        J -->|예| K[에러 메시지]
        J -->|아니오| L[데이터 표시]
    end
```

### 코드 패턴

```typescript
const data = ref<T | null>(null)
const loading = ref(true)
const error = ref<string | null>(null)

onMounted(async () => {
  try {
    data.value = await api.getData()
  } catch (e) {
    error.value = '데이터를 불러오는데 실패했습니다'
  } finally {
    loading.value = false
  }
})
```
