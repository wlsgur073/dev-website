# Frontend 프로젝트 문서

## 개요

이 문서는 `dev-website` 프로젝트의 프론트엔드 애플리케이션에 대한 기술 문서입니다.

### 기술 스택

| 분류 | 기술 | 버전 |
|------|------|------|
| 프레임워크 | Vue.js | 3.5.13 |
| 상태 관리 | Pinia | 2.3.0 |
| 라우팅 | Vue Router | 4.5.0 |
| HTTP 클라이언트 | Axios | 1.7.9 |
| 빌드 도구 | Vite | - |
| 스타일링 | Tailwind CSS | 3.4.17 |
| 언어 | TypeScript | - |
| 마크다운 | markdown-it, md-editor-v3 | 14.1.0, 6.3.1 |
| 코드 하이라이팅 | Shiki | 3.21.0 |

### 주요 기능

- **인증 시스템**: JWT 기반 로그인/회원가입/로그아웃
- **API 키 관리**: API 키 생성/삭제/재생성
- **사용량 대시보드**: API 호출 통계 및 모니터링
- **문서 시스템**: 마크다운 기반 기술 문서
- **공지사항/릴리스**: 관리자 CRUD 기능
- **다크 모드**: 시스템 설정 연동 및 수동 전환
- **반응형 디자인**: 모바일/데스크톱 대응

## 개발 환경 설정

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 5173)
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview

# API 타입 자동 생성
npm run gen:api
```

## 환경 변수

개발 환경에서 Vite는 `/api` 경로로 들어오는 요청을 `http://localhost:8080`으로 프록시합니다.

```typescript
// vite.config.ts
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

## 프로젝트 특징

1. **타입 안전성**: TypeScript strict 모드 활성화
2. **코드 분할**: 동적 import를 통한 페이지별 청킹
3. **토큰 자동 갱신**: 401 응답 시 자동 처리
4. **접근성**: ARIA 레이블, 포커스 스타일, skip-link 지원
5. **SEO 최적화**: 동적 메타 태그 관리
6. **성능 최적화**: 지연 로딩, 조건부 렌더링
